## 一、整体设计思路

"设置 → 账户"会变成一个独立子页面，分两大区：

### A. 微信登录区
- 未登录：显示"微信扫码登录"按钮 → 弹出二维码 → 微信扫码 → 自动登录
- 已登录：显示头像 + 微信昵称 + "退出登录"

### B. 学籍信息区（已登录或未登录都可编辑）
- 学号
- 姓名
- 学校
- 学院 / 专业
- 班级
- 入学年份 / 毕业年份
- 自定义字段（用户可加多个 key-value）

## 二、微信登录方式（**关键选择**）

### 选项 1：标准微信扫码登录（推荐，**真实可用**）
- 体验：点按钮 → 弹窗展示二维码 → 手机微信扫 → 自动绑定
- 需要：
  - 你有一个**微信开放平台账号**（open.weixin.qq.com）
  - 创建**"网站应用"**，拿到 AppID 和 AppSecret
  - 配置回调域名为 `localhost`（Electron 内置）
- 后端：用 AppID/AppSecret 换 access_token + openid（持久存数据库，标记"已绑定微信"）
- 注：拿不到真实头像/昵称（开放平台不返回），只能拿 openid 当唯一标识

### 选项 2：模拟微信登录（**演示用，无真实 API**）
- 体验：弹一个假的二维码 + 一个固定 token，直接"登录成功"
- 用于：UI 演示、离线开发、无需注册开放平台
- 你之后可以换回真方案

### 选项 3：跟小程序绑定（如果你选了 MINIPROGRAM 的 A 方案）
- 体验：在小程序里登录后，把 token 传回主程序
- 优点：拿得到头像昵称
- 缺点：必须先做小程序

**请选一个：** □ 1（真扫码） □ 2（模拟登录） □ 3（小程序联动）
