# Courses（课程）模块编辑扩展 - 待确认 + 规划

> 用户原话：**"讲课表中每个课程都可以被单独拿出进行编辑，如设置上课时间，作业内容，备注等"**

---

## 一、新增的编辑能力（梳理）

### 1. 课程本身（Course 表）
可编辑字段：
- 名称、课程代码、授课老师、学期、颜色（每门课独立配色）、课程描述/备注

### 2. 上课时间段（Events 表 + 周期性）
- 一门课一周可能多次（如"数据结构 周二 9:00-10:30 / 周四 14:00-15:30"）
- 每个时间段可独立编辑：
  - 周几
  - 起止时间
  - 地点
  - 备注（如"理实一体化教室"）
- 周期性：WEEKLY（每周重复）
- 支持单个时间段独立删除

### 3. 作业内容（Course_Requirements 表）
- 已有"添加作业"入口，需要补齐：
  - 编辑作业（标题、类型、截止时间、优先级、状态、预估工时）
  - 删除作业
  - 备注字段
  - 实际耗时记录（actual_hours，用于 vs 预估）

### 4. 课程级备注
- 描述（description）已有，可扩展为多段备注（时间戳 + 内容）
- 标签系统（自定义标签：考研重点 / 选修 / 待补修）

## 二、关键选择（请你回复）

### Q1：上课时间段的输入方式
- □ **"周几第几节"**（大学课表式：周二第1-2节）
  - 需要配置学期起始周和上课节次时段表（如"第1节=08:00-08:45"）
- □ **"周几 HH:MM-HH:MM"**（简单直接，推荐）
这种
- □ **两种都支持**（在 UI 里自由切换）

### Q2：编辑入口的交互形式
- □ **模态弹窗**（点击课程卡 → 弹出大弹窗，内含多个 tab：基本信息 / 上课时间 / 作业 / 备注）
- □ **侧栏抽屉**（点课程卡 → 右侧滑出抽屉，可同时看课程列表）
这种
- □ **独立页面**（点课程卡 → 整个工作区变成该课程详情）

### Q3：作业 / 要求列表的视图
- □ **列表 + 行内编辑**（点击直接编辑，最快）
这种
- □ **列表 + 详情弹窗**（点行弹窗编辑）
- □ **看板**（按状态分列拖动）

### Q4：上课时间段编辑
- □ **可视化时间网格**（像小米日历周视图，点格子添加）
这种
- □ **列表 + 表单**（每条一行，右边编辑按钮）
- □ **简洁表单**（纯表单一次填一个时间段）
