# 画布编辑器（达芬奇式节点连线）— v1.2.1 新功能

> 顶部菜单「Projects」→「画布视图」按钮即可进入。也可直接路由跳转 `/editor`。
> 老用户首次启动会自动迁移数据库；不需要手动建表。

---

## 1. 核心交互

| 操作 | 触发方式 |
|---|---|
| 新建节点 | 从左侧「节点工具箱」拖拽卡片到画布 |
| 移动节点 | 画布上按住节点卡片拖动（自动节流落库） |
| 删除节点 / 边 | 单击选中 → 按 Delete / Backspace；或在 PropertiesPanel 删除按钮 |
| 改属性 | 单击节点 / 边 → 右侧 PropertiesPanel 编辑 |
| 连线 | 鼠标移到节点 handle（小圆点）→ 拖到目标节点的 handle |
| 改线型 | 右键连线 → 弹出菜单 4 选 1；或在 PropertiesPanel 切换 |
| 改线 label | 单击连线 → PropertiesPanel「标签」输入框 |
| 打开关联实体 | 节点右上角 ⎋ 图标；或在 PropertiesPanel 「↗」按钮 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y（顶部 ↶ ↷ 按钮也可） |
| 导入 / 导出 | 顶部 ⬆ / ⬇ 按钮 |

## 3. 连线类型（4 种）

| 类型 | 视觉 | 典型语义 |
|---|---|---|
| 顺序 | 实线 🟢 | A → B：A 必须先于 B |
| 依赖 | 虚线 🔵 | A → B：B 依赖 A 完成（用于依赖图） |
| 关联 | 双线 🟣 | A ⇄ B：节点间有关联（如同时属于同一项目） |
| 关键 | 发光红 ✦ | A → B：关键路径上的强约束 |

---

## 4. 循环依赖检测

任何连线创建前会进行 3-coloring DFS 检测；成环则**拦截并提示环路径**，例如：

```
该连线会形成循环依赖：
N5 → N3 → N7 → N5

请先断开环路中的一条连线。
```

复杂度 O(V+E)，千节点 + 千边 < 1ms。

---

## 5. 撤销 / 重做

- **栈深度** 50（满则头部丢弃）
- **撤销**：回到操作前的状态（节点位置 + 属性 + 边）
- **切换画布**时清空历史（避免跨画布污染）
- **数据持久化**：撤销/重做会同步 DB（删除旧 → 按快照重插）
- **不记录**的操作：拖动过程坐标更新（只在松手时记录一次）

## 6. 导入 / 导出

### 导出

点击 ⬇ 按钮，下载 `<画布名>-<时间戳>.json`，结构：

```json
{
  "schema": "taskmanager.canvas.v1",
  "exportedAt": "2026-09-21T10:23:45.123Z",
  "canvas": { "name": "数据结构复习" },
  "viewport": { "x": 0, "y": 0, "zoom": 1 },
  "nodes": [...],
  "edges": [...]
}
```

### 导入

点击 ⬆ 按钮 → 选择 JSON → 预览节点/边数量 → 勾选「替换当前画布」或「追加」。

不兼容 schema 版本会被拒绝并显示原因。

## 8. 数据存储

画布数据存于以下 3 张表（迁移已自动应用，无需手动建表）：

- `canvases`：画布元信息 + 视口
- `canvas_nodes`：节点（位置、类型、关联实体 ID、标题、JSON 数据）
- `canvas_edges`：边（源 / 目标 / label / 类型）

业务实体通过 `canvas_nodes.entity_id` 外键引用，与 courses / project_tasks / events 表解耦（不设硬外键以避免级联删除风险）。

## 9. 限制与已知问题

- 节点库图标使用 lucide-react（项目已依赖）；新增类型请改 `src/components/editor/nodeRegistry.ts`
- 节点关联实体在导入 JSON 时不验证 entity_id 是否仍存在；导入端需自行保证一致性
- 自动保存已开（拖动松手 / 改属性即写 DB），无需手动 Ctrl+S
- 节点 / 边的归属 / 坐标系基于画布的 (0, 0) 原点；切换不会丢失位置
